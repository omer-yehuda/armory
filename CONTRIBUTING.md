# Contributing

This repository is maintained by [@omer-yehuda](https://github.com/omer-yehuda) and does **not accept external contributions**. Pull requests, issues and other changes from outside contributors are closed without review.

You are welcome to:

- **Use** the plugins: see the [README](README.md) for installation.
- **Fork** the repository and adapt it for your own use, under the terms of the [MIT License](LICENSE).

For security issues, see [SECURITY.md](SECURITY.md).
