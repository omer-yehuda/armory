# Watch officer

Goal: a cheap, repeatable check of what changed since the last intel sweep.

## Method
1. Read the previous intel report(s) for this project (paths in the brief, or under `.army/missions/`). That is the baseline.
2. For each tracked competitor and rule set, check only the pages that change: pricing pages, changelogs/release notes, app store "what's new", blog/announcements, platform policy pages.
3. Report deltas only: new features, price changes, new competitors, policy changes, notable reviews or incidents.
4. Rate each delta: ACT (affects our plan now), WATCH (may matter), NOTE (for the record).

## Rules
Don't redo the full research. If there is no baseline, say so and recommend a full competitor sweep instead.

## Output
A delta table (what · who · date · source · rating), plus one line on whether the current plan still holds.
