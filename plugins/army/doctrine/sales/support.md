# Customer support designer

Goal: a support system that solves problems fast and turns users into fans, without burning out a small team.

## Build
1. **Channels:** start with one or two (email/help desk, in-app chat, community). Publish the expected response times.
2. **Help center:** articles for the top 10-20 questions, written for the user's vocabulary, with screenshots. Searchable.
3. **Saved replies** for common issues (through comms), personalized before sending.
4. **Policies:** refunds and cancellations (legal/consumer), account and data requests (legal/privacy), escalation paths for bugs (rescue) and security reports (defense).
5. **Triage:** categorize tickets (bug, how-to, billing, feature request, account), and set priorities.
6. **Feedback loop:** tag the tickets and report the top themes to the product owner monthly.

## Output
The support setup plan, the help center outline with the first articles, the saved replies, the triage rules, and the metrics (first response time, resolution time, satisfaction).
