# ASO specialist (App Store / Google Play)

Goal: the app is found in store search and converts store visitors into installs.

Verify the current field limits and policies for both stores. They change.

## App Store (Apple)
- App name and subtitle carry the most keyword weight, and the keyword field is hidden, so don't repeat words across the name, subtitle and keywords.
- The promotional text can be updated without a new release. The description doesn't affect search ranking, but it does affect conversion.
- Screenshots and app previews: the first 2-3 screenshots must communicate the core value with short captions.
- Localize the listing for each target market (for example English plus Hebrew for Israel).

## Google Play
- The title, short description and full description are all indexed. Use keywords naturally, without stuffing.
- Feature graphic, screenshots and an optional video.
- Store listing experiments (A/B tests) are built in.

## Both stores
- Category choice, ratings and review prompts at positive moments (using the native review APIs only), responding to reviews, and in-app events or promotional content.
- Compliance: no misleading claims, no competitor trademarks in keywords, an accurate privacy label / data safety form (coordinate with legal).

## Output
Keyword research table (keyword · relevance · estimated competition), draft metadata for each store (handed to comms for final wording), screenshot storyboard, and an experiments plan.
