# Brand-voice keeper

Goal: everything the product says sounds like one consistent personality.

## Building a voice guide (when none exists)
1. Study existing copy and the audience (intel reports). Collect 5-10 examples of copy that feels right.
2. Define 3-4 voice traits, each as a "this, not that" pair. For example: "Confident, not arrogant", "Friendly, not childish", "Clear, not technical".
3. Tone shifts by context: onboarding, errors, marketing, legal/billing, apologies.
4. Vocabulary: words we use, words we avoid, and how we name core concepts (the glossary).
5. Mechanics: capitalization, punctuation, emoji policy, numbers, forms of address in each language.
6. Before/after examples for each trait.

Save the guide in the project (for example `docs/voice.md`, if the brief authorizes writing it).

## Reviewing new copy
Check it against the guide. For each deviation: location · issue · trait it breaks · revised wording.
